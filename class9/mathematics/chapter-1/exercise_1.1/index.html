Exercise 1.1, "Real Numbers and the Number Line," focuses on the visualization and properties of real numbers. This exercise defines the number line as a horizontal line displaying real numbers in ascending order (increasing from left to right), used for visualization, comparison, and solving arithmetic problems. How do we represent numbers on the number line? You will learn to represent various numbers on the number line: - Rational numbers (fractions): Example: $3/4$ (three-fourths) lies between 0 and 1, closer to 1 - Irrational numbers (surds): Example: $-\sqrt{8} = -2\sqrt{2} \approx -2.828$, lies between -3 and -2, closer to -3 - Integers: ..., -3, -2, -1, 0, 1, 2, 3, ... - Decimals: 0.5, -1.25, 2.75, etc. How do we represent inequalities on the number line? You will learn graphical representation of linear inequalities: - $x < 0$ (x is less than 0): All numbers to the left of 0. Open circle ○ at 0 (0 not included), arrow pointing left. - $x > 0$ (x is greater than 0): All numbers to the right of 0. Open circle ○ at 0, arrow pointing right. - $x \leq 2$ (x is less than or equal to 2): All numbers to the left of or at 2. Closed circle ● at 2 (2 included), arrow pointing left. - $x \geq -1$ (x is greater than or equal to -1): All numbers to the right of or at -1. Closed circle ● at -1, arrow pointing right. - $-3 < x < 3$ (x is between -3 and 3, not including endpoints): Open circles ○ at both -3 and 3. Shaded region between them. - $-4 < x \leq 4$ (x between -4 and 4, -4 not included, 4 included): Open circle ○ at -4, closed circle ● at 4. Shaded region between them. - Symbol summary: < (less than) = open circle ○, > (greater than) = open circle ○, ≤ (less than or equal to) = closed circle ●, ≥ (greater than or equal to) = closed circle ● What are the properties of equality of real numbers? A major portion of the exercise is dedicated to identifying the properties of equality: - Reflexive Property: For any real number a, $a = a$. Example: $9x = 9x$. - Symmetric Property: If $a = b$, then $b = a$. Example: If $2x + 3 = 7$, then $7 = 2x + 3$. - Transitive Property: If $a = b$ and $b = c$, then $a = c$. Example: If $x = y$ and $y = 5$, then $x = 5$. - Additive Property: If $a = b$, then $a + c = b + c$. Adding the same number to both sides preserves equality. - Multiplicative Property: If $a = b$, then $ac = bc$. Multiplying both sides by the same number preserves equality. - Additive Cancellation Property: If $a + c = b + c$, then $a = b$. - Multiplicative Cancellation Property: If $ac = bc$ and $c \neq 0$, then $a = b$. - Additive Inverse: For any real number a, there exists $-a$ such that $a + (-a) = 0$. - Multiplicative Inverse: For any real number $a \neq 0$, there exists $a^{-1} = 1/a$ such that $a \times (1/a) = 1$. - Distributive Property: $a(b + c) = ab + ac$. What are the properties of inequality of real numbers? You will also learn properties of inequalities: - Transitive Property: If $a < b$ and $b < c$, then $a < c$. - Additive Property: If $a < b$, then $a + c < b + c$. Adding the same number to both sides preserves the inequality direction. - Multiplicative Property (Positive multiplier): If $a < b$ and $c > 0$, then $ac < bc$. Multiplying by a positive number preserves direction. - Multiplicative Property (Negative multiplier): If $a < b$ and $c < 0$, then $ac > bc$. Multiplying by a negative number reverses the inequality direction.
